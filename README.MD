# A Beautiful Tale of Cyberpunk 2077

This is a **presentation website** about my favorite game, **Cyberpunk 2077**, and the cyberpunk genre in general.  
It covers the history of cyberpunk, main characters, game rules, and interesting facts about the world of Cyberpunk 2077.

The website is built using **HTML and CSS**, with modern layouts using **Flexbox** and **CSS Grid**.  
It is fully responsive and looks good on both desktop and mobile screens.

## Features

- Overview of the cyberpunk genre
- Information about Cyberpunk 2077: history, characters, and rules
- Clean and responsive layout
- Organized file structure for easy maintenance

## Technologies

- HTML5 for structure
- CSS3 for styling, Flexbox and Grid for layouts
- Git for version control
